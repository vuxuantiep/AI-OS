1. Identitäten – Entra ID

  • Benutzer: Cloud-only vs. Hybrid (synchronisiert)
  • Service Principals & Managed Identities
  • Gruppen: Security / Microsoft 365 / Dynamisch
  • Geräte: Entra joined, Hybrid joined, Registered
  • Gastkonten (B2B) und externe Zusammenarbeit

Was du tun musst:

  • Identitäten prüfen & verwalten (deaktivierte, inaktive, Gäste)
  • Gruppen sauber strukturieren (Namensschema je Einrichtung/Funktion)
  • Gerätestatus verstehen (Intune + Entra abgleichen)
  • Synchronisation klären: Entra Connect oder Cloud Sync? Fehler prüfen
  • Anzahl Konten ohne Anmeldung > 90 Tage dokumentieren
Benutzer öffnen Gruppen öffnen Geräte öffnen
PowerShell (Microsoft Graph, nur lesen) 
Connect-MgGraph -Scopes "User.Read.All","Group.Read.All","Device.Read.All","AuditLog.Read.All"

# Cloud-only vs. synchronisiert
Get-MgUser -All -Property DisplayName,UserPrincipalName,OnPremisesSyncEnabled,AccountEnabled |
  Select-Object DisplayName,UserPrincipalName,OnPremisesSyncEnabled,AccountEnabled

# Inaktive Konten (> 90 Tage, benötigt Entra ID P1)
$grenze = (Get-Date).AddDays(-90)
Get-MgUser -All -Property UserPrincipalName,SignInActivity |
  Where-Object { $_.SignInActivity.LastSignInDateTime -lt $grenze } |
  Select-Object UserPrincipalName,@{n='LetzteAnmeldung';e={$_.SignInActivity.LastSignInDateTime}}

2. Authentifizierung – MFA, Passwordless, CA

  • MFA erzwingen (über Conditional Access, nicht pro Benutzer)
  • Passwordless aktivieren (FIDO2, Passkeys, Authenticator)
  • Temporary Access Pass (TAP) für Onboarding
  • Self-Service Password Reset (SSPR)
  • Token-Flows verstehen (Refresh-Token, Sitzungsdauer)
  • Benutzer ohne registrierte MFA ermitteln
  • Legacy-Authentifizierung blockiert?
  • TAP-Richtlinie für neue Mitarbeitende geprüft
  • Lösung für geteilte Pflege-Tablets/Schichtgeräte geklärt
MFA & Passwordless Conditional Access Risky Users
PowerShell (nur lesen) 
Connect-MgGraph -Scopes "AuditLog.Read.All","UserAuthenticationMethod.Read.All","Policy.Read.All"

# Wer hat KEINE MFA registriert?
Get-MgReportAuthenticationMethodUserRegistrationDetail -All |
  Where-Object { -not $_.IsMfaRegistered } |
  Select-Object UserPrincipalName,IsMfaCapable,MethodsRegistered

# Conditional-Access-Richtlinien und Status
Get-MgIdentityConditionalAccessPolicy | Select-Object DisplayName,State

3. Autorisierung – RBAC, PIM, Conditional Access

  • RBAC-Rollenmodell (Entra-Rollen, Intune-Rollen, Exchange-Rollen)
  • PIM: Adminrechte nur „just in time" mit Begründung
  • Administrative Units je Einrichtung/Region
  • App-Berechtigungen & Graph-Scopes (Enterprise Apps, Consent)
  • Wer ist Global Administrator? (Ziel: 2–4 Personen + Notfallkonten)
  • Dauerhafte Adminrollen → PIM berechtigt (eligible)
  • Benutzer-Consent für Apps eingeschränkt?
  • Apps mit hohen Graph-Rechten (z. B. *.ReadWrite.All) gelistet
Rollen anzeigen PIM Enterprise Apps
PowerShell (nur lesen) 
Connect-MgGraph -Scopes "RoleManagement.Read.Directory","Directory.Read.All"

# Alle aktiven Rollen mit Mitgliedern
Get-MgDirectoryRole | ForEach-Object {
  $rolle = $_
  Get-MgDirectoryRoleMember -DirectoryRoleId $rolle.Id |
    Select-Object @{n='Rolle';e={$rolle.DisplayName}},
                  @{n='Mitglied';e={$_.AdditionalProperties.userPrincipalName ?? $_.AdditionalProperties.displayName}}
}

Der Operator ?? benötigt PowerShell 7.

Lizenzen Identity Governance
PowerShell (nur lesen) 
Connect-MgGraph -Scopes "Organization.Read.All","Group.Read.All"

# Lizenzbestand: gekauft vs. verbraucht
Get-MgSubscribedSku | Select-Object SkuPartNumber,ConsumedUnits,
  @{n='Gekauft';e={$_.PrepaidUnits.Enabled}},
  @{n='Frei';e={$_.PrepaidUnits.Enabled - $_.ConsumedUnits}}

# Gruppen mit Lizenzzuweisung
Get-MgGroup -All -Property DisplayName,AssignedLicenses |
  Where-Object { $_.AssignedLicenses.Count -gt 0 } | Select-Object DisplayName

5. De-Provisionierung – Offboarding

  1. Anmeldung sperren (Account deaktivieren)
  2. Sitzungen beenden (Refresh-Tokens widerrufen)
  3. Postfach → freigegebenes Postfach + Zugriff für Vorgesetzte
  4. OneDrive-Daten an Vorgesetzte übergeben / Aufbewahrung
  5. Gerät: Intune Wipe bzw. Retire (Firmen- vs. Privatgerät!)
  6. Gruppen & Rollen entfernen
  7. Lizenzen nach Frist entfernen
  8. Protokoll ins Ticket
Schreibende Befehle – nur mit Ticket/Freigabe und nach Vier-Augen-Prinzip ausführen.
Benutzer Offboarding Intune Geräte
PowerShell (SCHREIBEND) 
$upn = "vorname.nachname@emvia.example"   # anpassen
Connect-MgGraph -Scopes "User.ReadWrite.All","Directory.AccessAsUser.All"

Update-MgUser -UserId $upn -AccountEnabled:$false     # 1. sperren
Revoke-MgUserSignInSession -UserId $upn               # 2. Sitzungen beenden

# 3. Postfach umwandeln (Exchange Online Modul)
Connect-ExchangeOnline
Set-Mailbox -Identity $upn -Type Shared
Add-MailboxPermission -Identity $upn -User "vorgesetzt@emvia.example" -AccessRights FullAccess

# 7. Lizenz entfernen (SkuId aus Get-MgSubscribedSku)
# Set-MgUserLicense -UserId $upn -AddLicenses @() -RemoveLicenses @("<SkuId>")

Intune Geräte Compliance Policies

Connect-MgGraph -Scopes "DeviceManagementManagedDevices.Read.All"

# Nicht konforme Geräte

Domains / SSL-Zertifikateje AnbieterRegistrar / Webserver
  • Ablaufdaten aller Apple-Tokens notiert + Kalender-Erinnerung (−30 Tage)
  • Wer besitzt die Apple-ID für das Push-Zertifikat? (dokumentiert)
  • App-Secrets < 30 Tage ermittelt
App-Registrierungen
PowerShell (nur lesen) – ablaufende Secrets 
Connect-MgGraph -Scopes "Application.Read.All"
$grenze = (Get-Date).AddDays(30)
Get-MgApplication -All -Property DisplayName,PasswordCredentials,KeyCredentials | ForEach-Object {
  $app = $_
  foreach ($c in @($app.PasswordCredentials) + @($app.KeyCredentials)) {
    if ($c.EndDateTime -and $c.EndDateTime -lt $grenze) {
      [pscustomobject]@{ App = $app.DisplayName; Ablauf = $c.EndDateTime }
    }
  }
} | Sort-Object Ablauf
