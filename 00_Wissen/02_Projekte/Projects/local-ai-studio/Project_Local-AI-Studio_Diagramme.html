Architekturbild und Programmablaufplan (PAP) · Quelle: ai-studio-local/server.js und public/index.html · Stand 14.11.2026

1. Architektur: Wer spricht mit wem?

Die App besteht aus zwei Dateien. Der Browser zeigt die Oberfläche, ein kleiner Express-Server hält den API-Schlüssel und reicht Anfragen an Google Gemini weiter.

läuft im Browser läuft auf dem eigenen Rechner läuft bei Google Geheimnis

2. Programmablaufplan: Eine Nachricht senden

Der Ablauf von sendMessage() und streamResponse() im Browser sowie /api/chat auf dem Server. Rauten sind Entscheidungen, abgerundete Formen sind Start und Ende.

4. Beim Lesen aufgefallen

  • Fehlender Schlüssel bleibt stumm. /api/chat antwortet dann mit 401 als JSON. Der Browser erwartet aber einen Strom und zeigt nichts an, die Sprechblase bleibt auf „tippt …" stehen.
  • Die Modellliste ist fest eingetragen. Neue oder abgeschaltete Gemini-Modelle erscheinen erst nach einer Änderung in server.js. Das gilt auch für das Bildmodell.
  • „Offline" stimmt nicht. Die README nennt die App offline-fähig. Jede Antwort kommt aber von der Gemini API im Internet.
  • Kein Zugriffsschutz. Wer den Port 8080 erreicht, kann den Schlüssel überschreiben und auf dessen Kosten chatten. Für den eigenen Rechner ist das in Ordnung, für ein Netzwerk nicht.
