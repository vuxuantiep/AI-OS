4. Reihenfolge

Phase 1 · jetzt auf dem Laptop · leicht

Anmeldung und Tresor

  • Keycloak auf 26.8 heben, MFA an
  • LLDAP als Verzeichnis, an Keycloak koppeln
  • CISO Assistant und Dashboard per OIDC an Keycloak
  • Vaultwarden für Admin-Passwörter
  • Trivy-Scan aller Docker-Images
Phase 2 · auf dem N5 Pro · schwerer

Lebenszyklus und Protokolle

  • midPoint + PostgreSQL als eigene VM
  • HR-CSV, Rollen, Join/Move/Leave-Tests
  • Wazuh als eigene VM, Agenten auf Laptop, Pi, Proxmox
  • OPNsense-Logs an Wazuh
Phase 3 · Audit-Reife

Nachweis-Kreislauf

  • Assessment ISO 27001:2022 „Homelab“ im CISO Assistant
  • Erste Rezertifizierungskampagne
  • Greenbone-Scan monatlich
  • Entra-ID-Lab als zweites Zielsystem

Speicher beachten: midPoint (Java + Datenbank) und Wazuh (Indexer + Manager + Oberfläche) brauchen zusammen mehrere Gigabyte RAM. Auf dem Laptop greift sonst der RAM-Guard. Deshalb kommen sie erst mit dem N5 Pro. Genaue Mindestwerte vor der Installation in der Herstellerdoku prüfen.
